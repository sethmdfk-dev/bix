# ViX Remote

Compilar sin instalar nada:
1. Crea una cuenta gratis en github.com y un repositorio nuevo (privado o publico).
2. Sube TODO el contenido de esta carpeta (incluida la carpeta oculta .github).
3. Ve a la pestana Actions > "Build APK" > Run workflow (o espera a que corra solo).
4. Al terminar (unos 5 min), abre la ejecucion y descarga "ViX-Remote-APK" (zip con app-debug.apk).
5. Pasalo al celular e instalalo (permite "instalar apps de origen desconocido").

Alternativa: abrir la carpeta en Android Studio y usar Build > Build APK(s).
